# Quiet Kiss to the World — Web / Authorship Boundary

## Canonical technical fact

The `next-env.d.ts` file is generated and managed by Next.js. It exists to make Next.js-specific and non-code imports visible to TypeScript.

It is **not an authored artwork file** and should not be manually edited as part of the artistic layer.

When a Next.js web surface is implemented, the generated declaration should remain infrastructure, while authored expression should live in explicitly authored source files such as `app/page.tsx`, `app/layout.tsx`, styles, metadata, and provenance documents.

## Provenance boundary

- generated framework declaration: infrastructure
- authored interface: artwork / public surface
- repository history: provenance
- deployed page: distribution surface
- NFT metadata / CID: immutable reference layer

This separation prevents generated framework code from being mistaken for the artistic source of record.
